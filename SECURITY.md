# Security

This is an alpha developer preview, not an independently audited stable release. Do not use it on production subscribers without maintainer-led acceptance testing.

Do not disclose credentials, subscriber details, full provider responses or exploit instructions in a public issue. If GitHub shows **Security → Report a vulnerability**, use that private channel. If unavailable, open an issue asking a ReadySpace maintainer for a private reporting route, without sensitive details. No monitored private mailbox or response SLA is claimed here.

For suspected delivery/consent problems, switch sending Off and stop the scoped worker. Preserve redacted evidence and ledger records; do not clear the ledger, blindly resend or export subscriber data. Provider-accepted messages cannot be recalled by deactivating the plugin.
